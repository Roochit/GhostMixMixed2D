## 🎯 1. Systems Engineering & Physics 2D
*   **Raycast Optimization for Aiming Lines:** ออกแบบระบบเส้นนำสายตาอัจฉริยะในสคริปต์ `GhostSpawner` โดยใช้ `Physics2D.Raycast` ทำหน้าที่คอยตรวจจับระยะทางแบบเฟรมต่อเฟรม ตัดความยาวของ `LineRenderer` ให้หยุดอยู่แค่บริเวณปากขอบวัตถุชิ้นแรกที่เลเซอร์พุ่งชน (เช่น พื้นหม้อดิน หรือหัวของผีตัวอื่น) ไม่ปล่อยให้เส้นทะลุทะลวงลงไปใต้ฉาก
*   **Local Coordinates Mapping:** แก้ปัญหาวัดระยะเส้นเพี้ยนเมื่อปิด *Use World Space* ด้วยการเขียน Logic คำนวณความต่างพิกัดจุดตกกระทบ (`hit.point.y`) เทียบกับตำแหน่งสปอเนอร์ปัจจุบัน (`transform.position.y`) เพื่อแปลงระยะกลับมาเป็นค่าแกน Y ในระบบ Local Space ที่แม่นยำ
*   **Bouncy Mechanics Control:** ประยุกต์ใช้ `Physics Material 2D` ควบคุมค่าความเสียดทาน (`Friction`) และความยืดหยุ่น (`Bounciness`) ของตัวผีแต่ละเลเวล เพื่อสร้างฟีลลิ่งการร่วงหล่นที่เด้งดึ๋งนุ่มนิ่มสมจริงแทนการกระแทกแบบแข็งทื่อ

## 🎵 2. Advanced Audio Architecture
*   **Logarithmic Decibel Conversions:** แก้ไขบั๊กระบบเสียงวอลลุ่มดับแบบฮวบฮาบอันเนื่องมาจากระดับเสียงแบบ Linear โดยการใช้ฟังก์ชันทางคณิตศาสตร์คำนวณสเกลเสียงใหม่เป็นแบบเดซิเบล ($Mathf.Log10(\text{value}) \times 20$) ส่งเข้าไปควบคุมก้านเสียงใน **Audio Mixer** ทำให้หูมนุษย์ได้ยินเสียงเพิ่ม-ลดอย่างเป็นธรรมชาติ
*   **State-Driven Sound Controller:** เขียนระบบดักจับการทำงานของเพลงเบื้องหลัง (BGM) แยกสถาปัตยกรรมปุ่มกดออกเป็น 2 โหมด:
    *   **In-Game Scope:** ใช้ `AudioSource.Pause()` และ `UnPause()` ผูกสัญญานไปพร้อมกับการหยุดเวลาเกม (`Time.timeScale = 0f`)
    *   **Lobby Menu Scope:** สั่งปลดล็อคข้อจำกัดเรื่องเวลา ใช้การควบคุม Active State ของ UI หน้าต่างการตั้งค่า (`settingsPanel`) ควบคู่กับการเรียกคำสั่ง `Play()` เพื่อบังคับให้เพลงบรรเลงต่ออย่างต่อเนื่องเมื่อกดปิดเมนู
*   **Audio Mixer Routing:** บริหารจัดการเส้นทางเสียง (Audio Routing) โดยการแยก Groups เป็น `BGM` และ `SFX` ภายใต้ช่องสัญญาณ `Master` และทำการ **Exposed Parameters** รหัสคีย์เสียงออกไปภายนอกเพื่อให้สคริปต์ C# เข้าควบคุมได้อย่างอิสระ

## 💾 3. Data Persistence & UI Syncing
*   **Cross-Scene Data Syncing:** แก้ไขปัญหาก้านสไลด์เสียงเด้งกลับไปที่ 100% ตอนเปลี่ยนฉากหรือโหลดเริ่มเกมใหม่ โดยการประยุกต์ใช้ `PlayerPrefs.GetFloat` และ `SetFloat` ฝังข้อมูล `SavedVolume` ลงใน Harddrive ของเครื่องผู้เล่น เพื่อทำการบังคับให้ Slider UI วิ่งกลับมาอยู่ในตำแหน่งล่าสุดที่ผู้เล่นเคยตั้งค่าไว้เสมอ
*   **Explicit Event Dispatching for Frozen UI:** แก้ไขข้อจำกัดของระบบ Unity ที่ฟังก์ชัน `OnEnable()` หรือ `Start()` มักจะไม่ยอมประมวลผลคำสั่งสุ่มซ้ำเมื่อหน้าต่าง UI โผล่ขึ้นมาในขณะที่เกมหยุดเวลาอยู่ (`Time.timeScale = 0f`) โดยการเปลี่ยนโครงสร้างมาใช้วิธีสร้างฟังก์ชันเจาะจง `ForceRandom()` สั่งให้สคริปต์สุ่มรูปภาพและสุ่มคำศัพท์ทำงานทันทีแบบสดๆ ทุกครั้งที่มีการกดปุ่มหรือเปิดหน้าต่างแบบการันตี 100%

## 🖥️ 4. Responsive Screen Aspect Ratios
*   **Standalone Scaling Management:** แก้ปัญหาผู้เล่น Windows และ Mac เจอกรอบหน้าจอเกมแนวตั้งขยายใหญ่จนทะลุขอบบน-ล่างของหน้าจอ Notebook ด้วยการเขียนโค้ดบังคับสเกลให้รันแบบหน้าต่างลอย (`FullScreenMode.Windowed`) ล็อคขนาดเริ่มต้นที่ 600x800 พิกเซล (ซึ่งเป็นอัตราส่วนย่อส่วนลงมาจาก 1536x2048 ของ iPad สัดส่วน 3:4) และเปิดฟีเชอร์ `Resizable Window` ให้ผู้เล่นสามารถยืดขยายขนาดหน้าจอเองได้ตามความเหมาะสมโดยที่สัดส่วนภาพภายในไม่บิดเบี้ยว
